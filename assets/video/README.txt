Background reels for the Contributions section.

Drop one MP4 per project, using exactly these filenames:

  denshattack-bg.mp4
  lyra-bg.mp4
  tumbleup-bg.mp4
  chronofish-bg.mp4

Guidelines:
  - 15 to 30 seconds, looping cleanly
  - 1280x720, no audio track
  - under 8 MB each (GitHub allows 100 MB per file, but the page
    should stay fast)

The video sits behind the text at 16% opacity with a dark veil on
top, so pick footage with movement rather than fine detail.
If a file is missing the section simply shows the plain dark
background, nothing breaks.
